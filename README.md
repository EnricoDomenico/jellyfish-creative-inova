# 🪼 Jellyfish Creative - Website Moderno

Site institucional moderno e minimalista para a agência Jellyfish Creative, especializada em marketing digital de performance.

## ✨ Características

- **Design Moderno & Minimalista** - Interface clean e profissional
- **Animações Suaves** - Usando Framer Motion para transições elegantes
- **Totalmente Responsivo** - Otimizado para todos os dispositivos
- **Performance** - Construído com Next.js 14 para máxima velocidade
- **Tipografia Premium** - Fontes Inter e Lexend para legibilidade perfeita
- **Águas-vivas Animadas** - 5 águas-vivas com efeito de profundidade

## 🚀 Tecnologias

- **Next.js 14** - Framework React com App Router
- **TypeScript** - Tipagem estática para código mais seguro
- **Tailwind CSS** - Estilização moderna e responsiva
- **Framer Motion** - Animações fluidas e profissionais
- **Lucide React** - Ícones modernos e limpos

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Iniciar servidor de produção
npm start
```

## 🎨 Seções do Site

1. **Hero** - Apresentação principal com águas-vivas animadas
2. **Serviços** - Cards dos 4 serviços principais
3. **Nichos** - Mercados especializados (Imobiliárias, Clínicas, Advogados)
4. **Call to Action** - Conversão e contato
5. **Footer** - Links e informações de contato

## 🌐 Deploy

Recomendado deploy na Vercel para melhor performance com Next.js.
